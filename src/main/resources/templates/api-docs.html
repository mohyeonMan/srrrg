srrrg API

프로젝트 API key는 한 번만 표시됩니다. Authorization: Bearer srrrg_pk_... 헤더로 전달하세요.

공개 API는 links:read 목록 조회와 links:write 단일 링크 생성을 지원합니다. 생성 재시도에는 같은 Idempotency-Key를 사용하세요.

curl -H "Authorization: Bearer srrrg_pk_..." https://srrrg.link/api/v1/projects/{projectId}/links
curl -X POST -H "Authorization: Bearer srrrg_pk_..." -H "Idempotency-Key: request-1" -H "Content-Type: application/json" -d '{"originalUrl":"https://example.com"}' https://srrrg.link/api/v1/projects/{projectId}/links

모든 오류는 Problem Details 형식이며 code, requestId와 X-Request-Id를 포함합니다.

캠페인과 UTM 템플릿

campaigns:read/campaigns:write scope로 캠페인과 UTM 템플릿을 관리합니다. UTM 필드는 소문자로 시작하는 소문자·숫자·밑줄 2~50자이며 템플릿당 활성 필드는 최대 10개입니다.

curl -X POST -H "Authorization: Bearer srrrg_pk_..." -H "Content-Type: application/json" \
  -d '{"name":"봄 프로모션"}' https://srrrg.link/api/v1/projects/{projectId}/utm-templates
curl -X POST -H "Authorization: Bearer srrrg_pk_..." -H "Content-Type: application/json" \
  -d '{"name":"utm_source"}' https://srrrg.link/api/v1/projects/{projectId}/utm-templates/{templateId}/fields
curl -X POST -H "Authorization: Bearer srrrg_pk_..." -H "Content-Type: application/json" \
  -d '{"name":"봄 캠페인"}' https://srrrg.link/api/v1/projects/{projectId}/campaigns
curl -X PATCH -H "Authorization: Bearer srrrg_pk_..." -H "Content-Type: application/json" \
  -d '{"utmTemplateId":1}' https://srrrg.link/api/v1/campaigns/{campaignId}/utm-template

개인화 링크 대량 생성

JSON batch는 links:write scope와 필수 Idempotency-Key가 필요하며 요청당 최대 500개, 요청 전체가 성공하거나 전체가 실패합니다. utmValues에 없는 필드 이름을 보내면 400으로 거부됩니다.

curl -X POST -H "Authorization: Bearer srrrg_pk_..." -H "Idempotency-Key: batch-1" -H "Content-Type: application/json" \
  -d '[{"originalUrl":"https://example.com/a","externalId":"user-001","utmValues":{"utm_source":"newsletter"}}]' \
  https://srrrg.link/api/v1/campaigns/{campaignId}/links/batch

CSV 가져오기·내보내기

CSV 업로드도 Idempotency-Key가 필수입니다. UTF-8 또는 UTF-8 BOM, 최대 10,000행, 최대 10MB까지 지원하며 프로젝트당 동시 1개만 처리합니다. 업로드 직후 비동기 import ID를 반환하며 진행 상태와 행별 오류를 조회할 수 있습니다.

curl -H "Authorization: Bearer srrrg_pk_..." https://srrrg.link/api/v1/campaigns/{campaignId}/links/template.csv -o template.csv
curl -X POST -H "Authorization: Bearer srrrg_pk_..." -H "Idempotency-Key: upload-1" \
  -F file=@links.csv https://srrrg.link/api/v1/campaigns/{campaignId}/imports/csv
curl -H "Authorization: Bearer srrrg_pk_..." https://srrrg.link/api/v1/campaigns/{campaignId}/imports/{importId}
curl -H "Authorization: Bearer srrrg_pk_..." https://srrrg.link/api/v1/campaigns/{campaignId}/imports/{importId}/errors.csv -o errors.csv
curl -H "Authorization: Bearer srrrg_pk_..." "https://srrrg.link/api/v1/campaigns/{campaignId}/links.csv?createdFrom=2026-01-01T00:00:00Z" -o links.csv

UTM 값이나 externalId에 이메일, 이름, 전화번호 같은 개인정보를 넣지 마세요.

요청 한도

한도를 초과하면 429와 Retry-After 헤더를 반환합니다.

  • API key 조회: key당 분당 300회
  • API key 링크 생성: key당 분당 60회
  • JSON batch: 프로젝트당 분당 2회
  • CSV 업로드: 프로젝트당 시간당 5회
  • 대량 링크 생성: 프로젝트당 일 50,000개

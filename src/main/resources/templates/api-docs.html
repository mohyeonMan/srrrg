srrrg API

프로젝트 API key는 한 번만 표시됩니다. Authorization: Bearer srrrg_pk_... 헤더로 전달하세요.

공개 API는 links:read 목록 조회와 links:write 단일 링크 생성을 지원합니다. 생성 재시도에는 같은 Idempotency-Key를 사용하세요.

curl -H "Authorization: Bearer srrrg_pk_..." https://srrrg.link/api/v1/projects/{projectId}/links
curl -X POST -H "Authorization: Bearer srrrg_pk_..." -H "Idempotency-Key: request-1" -H "Content-Type: application/json" -d '{"originalUrl":"https://example.com"}' https://srrrg.link/api/v1/projects/{projectId}/links

모든 오류는 Problem Details 형식이며 code, requestId와 X-Request-Id를 포함합니다.

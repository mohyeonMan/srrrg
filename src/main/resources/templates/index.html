링크를 짧게.
이동은 신중하게.

srrrg는 긴 URL을 짧게 만들고, 신뢰되지 않은 링크는 이동 전 원본 주소를 확인하도록 돕는 단축 URL 서비스입니다.

API 문서 보기 OpenAPI JSON

단축 링크 만들기

긴 URL을 입력하면 바로 단축 URL과 관리용 secret key를 발급합니다.

secret key는 관리 기능에 사용할 예정이니 생성 직후 안전하게 보관하세요.

짧은 Base62 코드
